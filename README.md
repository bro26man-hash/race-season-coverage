# Race Season Coverage

Comprehensive race season coverage project — technical cornering analysis, driver physiology, multimedia assets, and race data for motorsport journalism.

## 📂 Project Structure

```
race-season-coverage/
├── README.md                  # This file
├── articles/                  # Written coverage
│   ├── technical-notes/       # Deep-dive technical reference documents
│   │   └── cornering-physics.md   # G-force & cornering physics from Wikipedia
│   ├── race-reports/          # Race summaries and analysis pieces
│   └── driver-profiles/       # Driver-focused feature articles
├── multimedia/                # Visual & audio assets
│   ├── photos/                # Race photography
│   ├── diagrams/              # Technical diagrams (cornering paths, G-load plots)
│   └── audio/                 # Podcast clips, commentary
└── data/                      # Raw & processed data sets
    ├── timing-data/           # Sector times, lap charts
    ├── sensor-data/           # Accelerometer, telemetry data
    └── stats/                 # Season standings, comparative stats
```

## 🏎️ Focus Areas

- **Cornering Physics** — lateral G-loads, centripetal acceleration, downforce aerodynamics, and the physical demands on drivers through high-G corners.
- **Driver Physiology** — G-tolerance, blood distribution effects, reaction time under load, and training methods.
- **Technical Analysis** — telemetry interpretation, sensor data, and quantitative race insights.
- **Multimedia Storytelling** — photo essays, annotated diagrams, and audio commentary.

## 📖 Reference Materials

Key technical references are stored in `articles/technical-notes/`. Each document is sourced from authoritative references (Wikipedia, FIA technical documents, team engineering notes) and formatted for easy citation in race coverage.

### Current Notes
- **Cornering Physics** (`cornering-physics.md`) — Extracted key facts from the Wikipedia *G-force* article covering lateral G-loads through corners, centripetal acceleration principles, downforce effects, and human tolerance limits.

## ✍️ Writing Guidelines

- Use metric units (g, m/s², km/h) as primary; include imperial conversions where useful for a broad audience.
- Reference the source file when citing physical constants or tolerance figures.
- Keep technical notes concise and scannable — bullet points and tables preferred for reference docs.

## 🤝 Contributing

Add new articles under `articles/`, multimedia under `multimedia/`, and data sets under `data/`. Maintain the folder convention above.
