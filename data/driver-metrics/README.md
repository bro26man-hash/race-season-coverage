# Driver Metrics

Physical and performance data for driver profiling.

## Files

- `g-tolerance.csv` — Max sustained lateral G per driver per session
- `heart-rate.csv` — Heart rate traces during race stints
- `neck-strength.csv` — Cervical strength assessment data
- `reaction-time.csv` — Reaction time test results (ms)

## Notes

- G-tolerance data derived from accelerometer extracts
- Physiological data sourced from team medical staff (confidential)
- Use for driver development stories and safety analysis
