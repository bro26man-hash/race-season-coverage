# Multimedia

All visual and audio assets for race season coverage.

## Subdirectories

- **`images/`** — Photography, diagrams, telemetry screenshots
  - `cornering-g-load-plots/` — Telemetry overlays showing lateral & longitudinal g
  - `circuit-maps/` — Track layouts with corner-by-corner annotations
  - `driver-portraits/` — Panoramic & action shots
  - `diagrams/` — Technical schematics (aero, suspension, brakes)
- **`video/`** — Interview clips, onboard footage references
  - `driver-interviews/` — Post-race & press conference clips
  - `onboard/` — Onboard camera references (with g-overlay)
  - `highlight-reels/` — Season & race-specific compilations
- **`graphics/`** — Data visualizations & infographics
  - `g-force-comparisons/` — Side-by-side cornering g comparisons
  - `telemetry-summaries/` — Sector charts, speed traces, braking points
  - `season-trends/` — Championship standings, reliability charts

## Asset Guidelines

- **Images**: High resolution (min 1920px wide); credit photographer & source in EXIF
- **Video**: Reference links preferred (YouTube, official broadcast); note timestamps for key moments
- **Graphics**: Export as SVG for diagrams, PNG for photo-based visuals; include source data in `../data/`
- **Licensing**: Log all usage rights; prefer Creative Commons or officially supplied media
